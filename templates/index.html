Local only

Paste a link from YouTube, Instagram (reels & posts), TikTok, X/Twitter, Facebook, and many more. Public content only — private or login-protected posts can't be fetched.

If Instagram says a post is login-protected, pick the browser where you're logged in — its cookies are read locally to authenticate the download. Close that browser first if it fails (Chrome/Edge lock the cookie store while running).

Click or drop songs (or any audio/video files)
Several songs? Each gets its own folder in the ZIP

Splits the track into a vocals file and an instrumental (music-only) file using the Demucs AI model. Both come back together in a ZIP. Runs fully on your machine — no upload to any server.

⚠ The first run downloads the ~80 MB AI model once. On a CUDA GPU a full song takes only a few seconds; on CPU it can take 1–4 minutes.

Click or drop big videos here

Cuts the video into clips small enough to send. The video is copied, not re-encoded, so there's no quality loss and it only takes seconds. Each clip is a normal playable video and downloads separately.
